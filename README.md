# Frontend Mentor Workspace

This folder contains multiple Frontend Mentor challenge projects. Each challenge lives in its own child folder and has its own HTML entry page.

## How to open any project

1. Open this folder in Visual Studio Code.
2. Open the challenge folder you want to view.
3. Open the file named `index.html` inside that folder.
4. Preview it in your browser.

### Recommended option: use Live Server

- Right-click the `index.html` file.
- Choose "Open with Live Server".
- The page will open in your browser.

### Simple option: open directly in the browser

- Double-click the `index.html` file.
- Or right-click it and choose "Open With" > your browser.
